# 🎮 Hangman Game

## 📌 Description

A simple command-line Hangman game developed using Python. The player has to guess the randomly selected word one letter at a time within a limited number of attempts.

## ✨ Features

- Random word selection
- Letter-by-letter guessing
- Limited attempts
- Prevents repeated guesses
- Displays guessed letters
- Shows the final result
- Simple and beginner-friendly command-line interface

## 🛠️ Technologies Used

- Python
- Random module
- Lists
- Loops
- Conditional statements
- String operations

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python hangman.py
